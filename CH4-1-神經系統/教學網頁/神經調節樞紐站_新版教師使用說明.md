# 神經調節樞紐站：教師使用說明

本頁配合翰林選修生物Ⅲ CH4-1「神經系統」，課本P96–107、原PPT60頁。開啟同資料夾的 `神經調節樞紐站_質感新版.html`；圖解、練習與簡報核心可離線使用。影片以相對路徑連到本單元的「教學影片」與「教學動畫」，移動時保留資料夾關係。

## 建議教學順序

1. 圖解1–5：從受器—中樞—動器建立訊息路徑；區分功能與形態分類，討論量測膜電位的參考電極。
2. 圖解6–14：先讀靜止、閾值與曲線座標，再連結Na⁺通道、K⁺通道、幫浦及不反應期。用第9、10關逐小題判讀，不把刺激強度軸和膜電位軸混用。
3. 圖解15–20：比較連續與跳躍傳導，沿Ca²⁺—胞吐—受體—局部電位建立化學突觸因果鏈。第11關與第18關檢查局部訊息整合。
4. 圖解21–27：比較腦和脊髓灰白質位置，沿背根輸入、腹根輸出追蹤反射。第12關逐步確認構造；第21關要求畫出上行與下行調節。
5. 圖解28–30、第13–15關：保留3道原PPT題，核對原文、原答案及模型界線。
6. 圖解31–32、第3、8關：自律神經是舊版延伸銜接，並非本次課本PDF的P118–119。可留到下一節，不將它計入CH4-1課文頁數。

## 操作與形成性評量

- 圖解右欄有教學重點、完整原文與思考筆記。長文自動分頁，保留全部字元；課本整頁和每張主要圖都可放大。全螢幕按鈕在「回到首頁」旁，方向鍵翻頁，Esc關閉放大圖。
- 練習上方有21關直接選題；表格判讀保留全部小題，每次顯示一小題。分類可拖放，也可點卡後點槽或用鍵盤操作，同類兩格可交換。
- 19關可自動檢核，2題開放探究只保存證據紀錄，不給客觀對錯分數。空白與未完成不算有效錯誤；第五次有效錯誤才揭露，診斷區分自行答對與揭露。
- 每單元分開保存已讀、位置、筆記、作答與結果；儲存不可用時提示並保留當次操作，仍可匯出。Aa提供20／22／24px，另有深色模式。
- 第20關建議用前軸突尖峰、末梢Ca²⁺、傳遞物釋放及後膜電位辨別阻斷環節；第21關要求局部反射與腦的上下行路徑，避免「反射完全不與腦有關」的結論。

## 需特別辨析的來源說法

| 來源 | 新版辨析 |
|---|---|
| PPT6列視桿／視錐為雙極神經元例子 | 保留原文；區分感光細胞與視網膜雙極神經元，不當同一細胞。 |
| PPT24將不反應期附在過極化附近 | 補充Na⁺通道失活的絕對期與通常需較強刺激的相對期。 |
| PPT26把刺激強度與閾值電位直接比較 | 閾值為膜電位條件，刺激強度與膜電位軸的單位不同。 |
| PPT43、原題二E說未達閾值便不傳遞 | 原題答案C、E保留；明示限於「當次未觸發新動作電位」模型，局部電位仍可整合；新版第18關採精確說法。 |
| 原解析「僅神經與肌肉產生動作電位」 | 本節典型細胞模型，不作跨所有細胞的絕對限制。 |
| 正常軸突朝末梢傳導 | 區分自然起始及不反應期與人工軸突中段刺激可雙向傳導的條件。 |
| 交感使支氣管舒張 | 人體需考慮循環腎上腺素途徑，不能僅畫成直接交感末梢支配所有氣道平滑肌。 |

閾值−50 mV、靜止−70 mV、峰值＋40 mV沿用本教材示意，不當所有神經元固定常數。髓鞘區與郎氏結保持完整原圖，不能說離子在空間跳飛；快速再極化主要是通道動態，不是幫浦瞬間搬回全部離子。
