## 素材、版面與座標策略

11 張課本整頁以 2 倍解析度轉圖，18 張原圖裁切以 4 倍解析度輸出。兩道原題完整 GIF 轉成 WebP 保留甲乙等標示；第三題六列文字表格依原 PPT 68 忠實重排 SVG，未生成或補造科學圖像。

動畫畫面以低閾值場景偵測、頁碼 OCR、取樣及逐頁目視交叉核對。每頁取起段、中央與末段代表畫面，頁內相同像素去重後保留末段，所有頁末 S3 均在；接觸表保存於素材資料夾。

圖解桌面目錄通常 180px、解說欄 340px，寬螢幕解說欄 380px；以當前頁首、教學卡、控制列量得可用高度，分頁保留全部字元。圖片採 contain 與原比例，沒有整頁縮放、剪切關鍵標示或內部題板捲動。填答參考欄由圖片比例、回饋與作答空間計算，不用硬套圖片放大倍數。題幹至少 20px；Aa 可切換內文字級 20／22／24px，較小工具字級依角色固定，不宣稱全部介面字都同步 24px。

本單元沒有 SVG 點選熱區；互動槽位以穩定 ID 及分類資料判定，不需要憑截圖重算熱區。資料保存 KEY 為 `hanlin.elective3.ch2-2.v1`，schema 2。文字與圖片來源全在單元內，不使用別章 storage。

配色集中在 CSS 變數：酒紅 `#7d344f`、暖象牙 `#f7f2ef`、玫瑰 `#f0dfe5`。深色模式與所有 24 組角色文字／背景對比實測，最低 4.96:1。正誤與完成另有文字／符號，不只依顏色。

### 失敗修正

首次深色大字測試在 1240×604 發現原題三完成後整頁高 620px，揭露後高 628px；門脈與脂質排序揭露後高 611px。保留原題所有文字與字級，縮短原題三選項間距，讓適配函式加計底列、回饋與外層 padding 的 42px 預算。修正後以最終版重跑受影響狀態及全單元回歸，全部通過，首次失敗 JSON 仍保留供追溯。

素材目視核對時恢復管壁圓圖、胃標題、食性動物頭部、激素圖例及知識框的完整裁切範圍。首頁及診斷頁修正沿用前章的圖說、P32–P44 與 PPT64 計數；唾腺觀察改用 PPT28 原照片，三個吸收尺度改用 PPT49 完整示意圖。原題三表格 XML 文字跨行，驗收以實際解析後文字比對而非要求 XML 原始字串連續。
