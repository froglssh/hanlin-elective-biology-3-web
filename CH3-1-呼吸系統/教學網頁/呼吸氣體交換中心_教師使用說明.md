# 呼吸氣體交換中心｜教師使用說明

適用：翰林選修生物Ⅲ CH3-1，課本印刷 P70–P75。開啟同資料夾的 `呼吸氣體交換中心_質感新版.html`。原網頁與原 index 保留，尚未替換正式入口或公開發布。

## 教學安排

- 圖解 1–6：區分通氣、交換、血液運輸與細胞呼吸，從蚯蚓／昆蟲比較進入人體構造。請學生沿鼻腔至肺泡追蹤空氣，再辨認交換屏障。
- 圖解 7–11：先排出肌肉→容積→肺泡壓→氣流因果鏈，再讀肺內與胸膜腔兩條曲線。吸氣末肺泡壓回到相對0時，請學生說明為何肺仍較大。
- 圖解 12–14：比較中央、周邊化學受器，再建立CO₂負回饋。強調橫膈及肋間肌的體運動神經輸出。
- 圖解 15–19：比較PO₂、Hb飽和度與總含氧量；區分沿曲線移動與整條曲線位移。CO₂運輸先追組織端，再反向追肺部。
- 圖解 20–23：核對完整原題與原答案；原題三須同時處理數值、曲線依據、生理意義及主要氣體形式。

每張圖解提供「教學重點」「原文與圖說」「思考筆記」。右側解說依實際可用高度分頁，不刪除後續文字；完整課本頁另有放大入口。全螢幕按鈕位於回首頁旁，僅投影教學卡與精簡控制；方向鍵可換卡，Esc關閉圖片或退出全螢幕。

## 科學核對提醒

1. 肺並非完全沒有肌肉：沒有能獨立驅動通氣的骨骼肌，但氣道有平滑肌。[通氣機制](https://openstax.org/books/anatomy-and-physiology-2e/pages/22-3-the-process-of-breathing)
2. 胸膜腔壓負值不能單獨判定吸氣。需比較肺泡壓與大氣壓，且「胸膜腔壓持續負值」限圖示安靜呼吸。[壓力關係](https://openstax.org/books/anatomy-and-physiology-2e/pages/22-3-the-process-of-breathing)
3. 原PPT19的「交感神經」輸出改以呼吸肌體運動神經理解；中央受器主要回應CO₂造成的局部H⁺變化。[呼吸調節](https://openstax.org/books/anatomy-and-physiology-2e/pages/22-3-the-process-of-breathing)
4. 左移表示相同PO₂下親和力較高，不能說完全不釋氧；分壓、飽和度與總含氧量不是同一數量。[氧運輸](https://openstax.org/books/anatomy-and-physiology-2e/pages/22-5-transport-of-gases)
5. HCO₃⁻主要在紅血球形成，主要在血漿運輸；CO₂結合Hb球蛋白而非血基質鐵。教材7／23／70%是近似模型。[CO₂運輸](https://openstax.org/books/anatomy-and-physiology-2e/pages/22-5-transport-of-gases)
6. 原題三保留15%原答案，解說以95%−80%=15個百分點說明其分母；若問相對原先已結合氧的釋出比例，才是15／95約15.8%。原圖下方另有「肌紅蛋白」文字，本題依上方肌紅素虛線與血紅素實線判讀，不推定另一條曲線。
