# 內分泌訊號調度站｜教師使用說明

適用：翰林選修生物Ⅲ CH4-4〈內分泌系統〉；課本 P120–P134。製作日期：2026-10-08。

開啟：[新版網頁](內分泌訊號調度站_質感新版.html)。本機預覽：[內分泌訊號調度站](http://127.0.0.1:8804/教學網頁/內分泌訊號調度站_質感新版.html)。原網頁與 index.html 保留。

## 四條教學路徑

- **圖解探索**：36 張圖解，依來源與標的、腺體與激素、受體與傳訊、回饋與恆定、壓力與失調、原題與證據整理。教學重點、原文與圖說、思考筆記分頁；長文以翻頁閱讀，完整 PDF 頁圖可開啟放大。圖4-26跨頁統整圖同時保留兩部分。
- **互動練習**：24 關，上方數字可直接選關；22 關有答案檢核，另有2題開放證據紀錄。分類題可點選、拖放或鍵盤操作，同組兩格允許交換。第9–12關採逐小題閱讀，參考圖放左欄；原題附圖放右欄，題目及關卡列仍在上方通欄。
- **課堂簡報**：57 頁原簡報、236 個動畫代表畫面，可依頁選取及逐步翻看。代表畫面是由逐秒影格去除近似重複整理，不是原PPT按鍵次數的重建。原PPT逐頁文字可完整閱讀；另可播放原始約5分20秒動畫。
- **教學影片**：使用本章原影片，約18分35秒；支援原生播放及進度移動。

Aa提供20／22／24px主要閱讀字級；短視窗的控制列與輔助標籤維持精簡尺寸。深色模式提供另一套酒紅、霧玫瑰色階。桌面圖解當頁與練習初始必要操作可同窗閱讀；手機改為自然垂直閱讀。原圖細字可點圖放大，不裁掉圖說或箭頭。

「全螢幕播放」在「回到首頁」旁，呈現教學卡與精簡控制列；退出後回到原閱讀位置。圖片視窗在全螢幕內也可開啟，Esc關閉後焦點回到原控制。

## 建議授課順序

1. 圖解1–4：以「來源→血液→受體→效應」建立框架，再比較神經與內分泌。
2. 圖解5–19：優先比較下視丘／前後葉、皮質／髓質及胰島／胰液，避免只背器官名。
3. 圖解20–23、練習1與10：追蹤第一傳訊者、cAMP及級聯放大；再用胰島素、GH提醒模型的適用範圍。
4. 圖解24–29、練習2、11、12：沿促進／抑制箭頭推論，把「回路負回饋」與「兩激素拮抗」分開。
5. 圖解30–33、練習3、8、22：比較交感－髓質與HPA－皮質途徑，以及適應與長期代價。
6. 練習13–15：回到原PPT三道題；練習23–24則要求提出假說、預測及可區分的資料。

## 作答保存與診斷

同一瀏覽器、本機網址下自動保存閱讀、草稿、思考筆記、字級及模式。有效完整作答錯誤達5次才揭露答案；不完整作答不算錯誤。揭露答案與自行答對分列，開放紀錄不自動判分。診斷可回到相關圖解，並匯出JSON或文字筆記。

更換瀏覽器、網址埠或清除網站儲存會改變保存範圍。儲存不可用時，頁面顯示提示且仍可繼續練習。教師可使用匯出紀錄，不需輸入學生個資。
